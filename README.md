# My Simple To-Do

Create a simple To-Do List web application for a beginner web development project. Use HTML, CSS, and JavaScript. For the first step, create only the basic structure and design. Requirements: - A clean and modern To-Do List interface. - A page title: "My To-Do List". - An input field where the user can enter a task. - An "Add Task" button. - An empty task list area. - A responsive design that works on desktop and mobile. - Use a simple, beginner-friendly layout. - Do not add a backend or database. - Keep the code simple and easy to understand. Do not add advanced features yet.
